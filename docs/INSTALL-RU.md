# Установка программы MyOriShop — простая инструкция

Это программа для учёта склада. Она работает **прямо в браузере** (как сайт), но
**без интернета** — всё хранится на вашем компьютере. Установить её нужно **один
раз**. Ниже — по шагам. Если что-то пойдёт не так, ничего страшного: испортить
компьютер этими действиями нельзя.

---

## Что у вас должно быть

Один файл с именем вроде **`MyOriShop-Setup-1.14.exe`** (цифры могут отличаться).
Его передал вам муж. Это и есть установщик программы.

---

## Шаг 1. Запустить установщик

Найдите файл `MyOriShop-Setup-...exe` (обычно в папке «Загрузки» или на рабочем
столе) и **дважды щёлкните** по нему левой кнопкой мыши.

---

## Шаг 2. Пройти синее окно Windows (важно!)

Может появиться **синее окно** с надписью **«Система Windows защитила ваш
компьютер»**.

**Это нормально и не значит, что программа плохая.** Так Windows реагирует на
любую программу, за которую пока не заплачена специальная «цифровая подпись».
Программа безопасна — её сделал муж.

Сделайте так:

1. Нажмите на маленькую надпись **«Подробнее»** (она в этом же синем окне).
2. Внизу появится кнопка **«Выполнить в любом случае»** — нажмите её.

> Если синего окна не было — просто переходите к Шагу 3, всё в порядке.

---

## Шаг 3. Дождаться установки

Программа установится **сама**, ничего вводить не нужно. Пароль администратора
Windows **не потребуется**. Дождитесь, пока установка закончится.

---

## Шаг 4. Открыть программу

1. Нажмите кнопку **«Пуск»** (значок Windows слева внизу).
2. Начните набирать слово **MyOriShop** — в списке появится программа с таким
   названием.
3. Щёлкните по ней.

---

## Шаг 5. Программа открылась

Через пару секунд **сам откроется браузер** (Edge, Chrome — что стоит по
умолчанию), и в нём появится **страница входа** в программу. Готово — можно
работать.

> Рядом может появиться маленькое **чёрное окошко**. **Не закрывайте его, пока
> работаете** — это «моторчик» программы. Когда закончите работу, программу
> закрывают именно закрытием этого чёрного окошка.

---

## Как открыть программу в следующий раз

Просто повторите **Шаг 4**: «Пуск» → набрать `MyOriShop` → щёлкнуть. Синее окно
(Шаг 2) больше не появится — оно только при самом первом запуске.

---

## Если что-то не так

- **Браузер не открылся сам.** Откройте браузер вручную и введите в адресной
  строке: `http://127.0.0.1:8000`
- **Ничего не появляется / ошибка.** Закройте чёрное окошко, откройте программу
  заново через «Пуск» (Шаг 4).
- **Совсем не получается.** Сфотографируйте экран с ошибкой и отправьте мужу.

---

## Как удалить программу (если понадобится)

«Пуск» → **«Параметры»** → **«Приложения»** → найти **MyOriShop** → **«Удалить»**.
Программа ставится только для вашего пользователя, никаких следов в системе не
оставляет.
