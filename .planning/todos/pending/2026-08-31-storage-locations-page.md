# Страница мест хранения товаров

**Area:** ui
**Created:** 2026-08-31
**Status:** pending

## Problem

Оператор не может быстро узнать, где физически лежит товар. Место хранения (полка)
записывается в поле «Комментарий» партии — например `полка 59`, `под зеркалом`, —
но отдельного экрана, показывающего склад по местам, в приложении нет. При приёмке
и сборке заказа приходится вспоминать расположение по памяти.

Актуально прямо сейчас: расшифрована опись склада «Офис» на 414 партий по 23 местам
(`reports/оприходование-офис-2026-08-31.csv`), полка каждой партии проставлена
в комментарий.

## Solution

Новая страница в разделе «Товары»:

1. **Кнопка перехода** на странице товаров → список товаров на складе,
   сгруппированный по месту расположения.
2. **Место** берётся из поля `comment` партии (`batches.comment`).
3. **Пагинация** и удобная навигация по местам (переход к конкретной полке
   без пролистывания всего списка).
4. **Поиск**: оператор вводит название или код товара — система отвечает,
   где что лежит (место + количество по партиям).

Открытые вопросы к проработке:
- парсинг места из свободного текста комментария vs. отдельное поле
  (в модели `Batch` уже есть неиспользуемое поле `location`);
- поведение для партий без указанного места.
