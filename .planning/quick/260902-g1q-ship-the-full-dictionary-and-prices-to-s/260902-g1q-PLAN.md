<objective>
Make the two existing catalog importers able to move the FULL local reference data
(dictionary 12 582 codes, catalog_prices 15 798 rows) to s1, where today there is only the
6 856-code master-price subset — additively, without touching a single row that already
exists on the server.

Purpose: `catalogs/products.json` is lost (not on disk, not in git) and
`catalogs/price_lists/` (240 files, 118 MB) is deliberately kept out of git and out of the
Docker image. The 12 582 names therefore live in exactly ONE place: `data/myorishop.db`.
Compact JSON exports of the two tables are the only transport that fits the existing
`git pull` + image-rebuild deploy. On top of that, `import_catalogs.py` currently creates
`Dictionary` rows with no `rubric` and no `name_lc` — every row it ever wrote is invisible
to the /dictionary name filter and has no category. That bug is fixed here, in place.

Output: two extended scripts (no new scripts, no new packages), one test module each, the
two committed export files, and a written rehearsal of the exact additive command sequence
the orchestrator will later run on s1.
</objective>
