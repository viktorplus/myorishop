# Итог

Пять публичных страниц заменены одной сводной:
**https://ori.viktorplus.com/otchet-prihodov**

Страница закрывает всё, что добавлялось на склад «Офис» по фотографиям
рукописных описных листов с 31.08 по 12.09.2026 — четыре партии, 134 листа,
1495 строк, 7497 шт, 831 код. Товар, вносившийся по одному через программу,
в отчёт намеренно не входит.

## Что на странице

- Сводная таблица четырёх партий.
- Правило доверия к названиям: надёжно только то, что взято из прайс-листа,
  признак — наличие каталожной цены. Таких 773 кода из 831. Остальные 58
  разложены по причине: 19 по регистрационным документам Oriflame, 8 из
  справочника без подтверждения ценой, 12 своих кодов оператора, 19 «Не опознан».
  Все 58 перечислены поимённо.
- По каждой партии — «Не добавлено», «Без названия», «Перепроверить».
- Сроки годности по всем партиям: 2296 годен, 1225 без срока, 3976 просрочено.
- Как проверялось распознавание.
