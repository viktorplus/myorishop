# Одна публичная страница вместо пяти

## Задача

Свести всё, что добавлялось на склад **по фотографиям рукописных листов**,
в один публичный отчёт с разделами по датам. Товар, вносившийся по одному
через программу, в отчёт не входит.

В каждом разделе: что добавлено, что НЕ добавлено, что осталось без названия,
что нужно перепроверить.

Отдельно — правило доверия к названиям: надёжны только те, что взяты
из прайс-листов (признак — есть каталожная цена). Всё остальное помечается
как требующее проверки соответствия.

Пять прежних публичных страниц удалить.

## Что заменяется

| Старый адрес | Чем был |
|---|---|
| `/code/artifact/0ac2f0bf-…` | опись склада «Офис» |
| `/code/report/office-import-2026-09-02` | отчёт по её импорту |
| `/code/report/unknown-codes-2026-09-02` | список неопознанных кодов |
| `/code/artifact/143c5a2c-…` | приход 1355 шт 03.09 |
| `/code/report/office-receipt-2026-09-07` | приход 1735 шт 07.09 |

Новый адрес — `/otchet-prihodov`, читаемый вслух.

## Проверка «сделано»

- Аноним получает `/otchet-prihodov` без входа, все пять старых адресов не 200.
- Соседние пути (`/otchet-prihodov/other`, `/products`) остаются за логином.
- Каждая из четырёх партий имеет свои «Не добавлено», «Без названия»,
  «Перепроверить».
- Цифры на странице сходятся с файлами импорта и с боевой базой.
- Полный набор тестов зелёный, ruff чистый.
- Страница открыта в браузере на боевом домене.
