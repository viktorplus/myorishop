and Task 3's verify is `git diff --numstat HEAD~1 -- reports/`. In reality
`git ls-files reports/` was empty — the whole directory was untracked (it is **not**
gitignored: a `git check-ignore -v reports/` hit pointing at a blank `.gitignore:48`
is a false positive; `git check-ignore` on the file itself exits 1 and `git add`
without `-f` works). Consequences:
- The planned numstat check could not produce evidence, so the safety net was
  replaced by a **stronger, equivalent one**: both files were copied to the scratchpad
  *before* any edit, and the result was diffed against those backups (+43/−43 lines,
  only columns 3 and 9; 86 changed XLSX cells). No `git add -f`, no `.gitignore` edit.
- The Task-3 commit **adds** the two files to git for the first time, so
  `git show --numstat HEAD` reads `415 0` for the CSV (whole file new) rather than
  `43 43`. If keeping `reports/` out of git was deliberate, undo with

  — the files stay on disk.
