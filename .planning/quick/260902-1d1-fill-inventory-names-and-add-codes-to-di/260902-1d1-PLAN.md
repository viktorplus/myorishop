cannot be оприходованы or recognised. The names are already resolved (19 from official

mechanism must therefore be able to carry a code that has a name but no price, which it
currently cannot.

for the names), an extended `scripts/import_master_pricelist.py` that turns override-only
codes into priceless dictionary rows (+ tests), and the CSV/XLSX pair with all 43 rows
filled and their «Проверить» notes updated.
</objective>
