# Довести восстановление оттенков до карточек товаров

## Что осталось незакрытым

Задача 260902-k2i починила 607 названий в справочнике. Карточки товаров
(`products.name`) остались со старым голым оттенком: приход намеренно не
переименовывает существующий товар (PD-9), а импорт описи создавал карточки из
CSV, где стоял оттенок.

На s1 отстают ровно 5 карточек — те, что завела опись «Офис»:

## Ловушка, из-за которой нельзя синхронизировать «карточки из справочника»

Всего расхождений между `products.name` и `dictionary.name` на s1 — **17**.
Кроме этих 5, есть **12 ОБРАТНЫХ**, где карточка богаче справочника, потому что
оператор вписывал название руками:

```
21566  карточка: Женские туалетные духи Volare Magnolia объем 50 мл
       справочник: Туалетные духи volare magnolia
25048  карточка: Мужская туалетная вода Tycoon75 мл
       справочник: Туалетная вода tycoon
```

Массовая синхронизация уничтожила бы эти 12 названий. Правило оператора — при
конфликте побеждает более полное — здесь оставляет победителем карточку.

## Что делать

Расширить **уже существующий** режим `--restore-shade-names` в
`scripts/import_catalogs.py`: после обновления строк справочника пройти по
`products` и обновить `name` там и только там, где выполняется тот же предикат
`is_shade_tail(product.name, dictionary.name)` из `app/services/rubrics.py`.

- предикат уже написан, использовать его, не переписывать;
- обновлять `name` И `name_lc` (теневая колонка поиска, LIST-02 — без неё
  товар пропадёт из поиска по названию);
- `category` не трогать: это отдельное поле, у него свои правила;
- сухой прогон по умолчанию, запись по `--apply` — как у существующего режима;
- идемпотентность: повторный прогон обновляет 0 карточек;
- печатать отдельной строкой «Карточек товаров обновлено: N», не смешивая со
  счётчиком справочника.

## Проверки

- На s1 предикат выбирает ровно 5 карточек; 12 обратных расхождений остаются

- Ни одно имя карточки не стало короче.
- `name_lc` соответствует новому `name` у каждой изменённой строки.
- Полный `uv run pytest`; падения `tests/test_sync_ui.py` известны (состав
  плавает из-за гонки `_run_lock`), не чинить.
